# Visual Effects Directory

This directory houses canvas and festive visual effects for Raas~Rang.

## Current Implementations
- `ParticleCanvas.tsx`: Ambient festive Garba golden particle system with sway, multi-color palette, and visibility throttling.
- `Preloader.tsx`: 3.4-second cinematic temple opening sequence featuring Web Audio API temple bell harmonics (432Hz harmonics) and emblem reveal.

## Future Festive Expansions (Navratri 9-Day Expansion)
This folder is architected to easily receive future modules:
1. `FallingPetals.tsx`: Marigold flower petal physics simulation during Navratri days.
2. `DiyaGlow.tsx`: Dynamic radiant flickering lighting along the temple arch.
3. `GarbaRing.tsx`: Concentric rhythmic rotating mandala backgrounds.
4. `MandalaInteractive.tsx`: Mouse-reactive sacred geometry layers.
